# 2026-10-29 · 同行（Kelin 团队）出片经验：吸收与省钱

来源：Kelin 发来的 `ai-video-workflow` skill 包（`references/02-visual-direction.md`、`03-prompts.md`、`04-generation.md`）与 10-29 的聊天。
他们实测「基本不用抽卡，每条最多剪掉一两个镜头」，一天视频消耗几百元。

## 他们怎么做

- **提示词全程一种语言，全英文最准。** 剧本与提示词都用 Claude 写，不用 OpenAI（Codex）的模型；他们是在 Claude 订阅里写好再贴进生成工具。
- **两套流程：**
  - 精控：Claude 脚本 + GPT「人物版」（人物设定图）+ 商品各角度图 + Seedance 2.5。前提是提示词写全。
  - 省钱：Claude 脚本 + GPT 故事板（出故事板时就查画面）+ 商品各角度图 + Seedance 2.0。「故事板没错，视频就不会错」，抽卡放在故事板环节。
  - UGC 类用 MiniMax H3 / Wan 3 就够，省钱。
- **参考图各管一件事：** 人物卡管面部、发型、服装、体态；商品图管款式结构；场景图管空间。提示词里写清每张图负责什么、不继承什么。
- **每个镜头核对六项：** 主体与表演、空间 / 调度、构图、摄影机、光色、声音 / 剪辑。镜头按「首态 → 主动作 → 尾态 → 下一拍衔接」写，一拍一个主动作、一个机位意图。
- **首帧放在主动作发生之前的清楚状态**，不提前露出结果。
- **提示词紧凑**：画幅与呈现 → 参考职责 → 首态与空间 → 时间与动作 → 声音 → 尾态 → 关键限制；禁止项只留当前风险，不写互相重复、互相矛盾的要求。

## 省钱账（Shuyu 10-29 价目表，15 秒、720P 档）

| 线路 | 15 秒点数 | 备注 |
| --- | --- | --- |
| MiniMax H3 768P | 360 | 比现行默认省 76%；Kelin 说 UGC 够用 |
| Grok 1.0 / 1.5 | 360 / 480 | |
| Kling 4.0 | 780 | 10 张参考图；可能接得住人脸（待验证） |
| Wan 3.0 | 960 | |
| Seedance 2.0 VIP | 1,560 | 比现行默认还贵 |
| **Seedance 2.5 特价（方案 113，现行默认）** | **1,500** | **按次计价，5–30 秒同价** |
| 故事板一帧（GPT Image 2，2K） | 32 | 约等于视频的 1/47 |

1. **抽卡挪到故事板。** 一帧 32 点，一条视频 1,500 点。成片不能用就得整条重出，所以故事板阶段多抽几帧、把住关再出片最便宜。我们已有「AI 审帧」（`STORYBOARD_AI_REVIEW=block`，线上默认关），打开就是他们省钱流程里的「故事板阶段查画面」。
2. **长视频用方案 113 的按次计价。** 现在 15 秒以上拆段再拼：30 秒 = 2 段 = 3,000 点。单段 30 秒只要 1,500 点，还没有接缝。Shuyu 价目表常漂移，先真机提交一条 30 秒确认真按次扣。
3. **UGC 走 H3。** 360 点 / 15 秒。质量先用评测集比，赢了或持平再分档。
4. **人脸重的故事别硬上 Seedance。** 10-29 评测里画面有清楚正脸的视频 5 条全失败（Shuyu 只回「原因不明」，还说过「参考图校验暂不可用」），每次白等约 8 分钟、白花 4 帧。Shuyu 上的 Kling 4.0 每条 780 点，比现在还便宜，可以作为人脸故事的线路，待评测。
5. **写提示词改 Claude 的成本很小。** 每条视频约 5 次调用，按 1 万输入 + 1.25 万输出 token（含思考）估：Opus 5.5 约 $0.29、Sonnet 5.5 约 $0.15、Haiku 5.5 约 $0.007；固定的系统提示可以缓存。
   他们「订阅里写好再贴进去」适合人工做片；我们是给商家自动出片，必须走 API——订阅不能拿来自动驱动产品。
