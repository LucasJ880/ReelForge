## 一、阻塞验收的（建议先谈）

### 1. 抠图服务（二选一）

| 选项 | 环境变量 | 定价参考 | 备注 |
|---|---|---|---|
| remove.bg | `REMOVE_BG_API_KEY` | 按张计费，订阅约 $0.13-0.20/张 | 电商抠图老牌，边缘质量稳 |
| Clipdrop (Stability) | `CLIPDROP_API_KEY` | 按调用计费 | 同一接口形状，适配器已支持 |

**阻塞什么**：
- B1 产品锚定全链路（锚点 = RGBA 切片 + mask，没有抠图就没有锚点）
- B1 验收标准：同一 SKU 跨 10 次生成校验通过率 100%
- B2 默认档切换：自然植入要锚点 READY 才会自动升档（决策 3 的落地）

**key 到位后的动作**：配好环境变量 → 跑 `processPendingAnchors()`（已建的续跑入口，
停在 PENDING_CUTOUT 的锚点自动补齐，商家不用重新提交）→ 跑 B1 十次验收。

**将来可换**：开源 SAM / BiRefNet 自建（PRD §13 的另一选项）。适配器已隔离，
换供应商不动业务代码 —— 这正是「留好将来能换掉的接缝」。

## 二、可后接的（O4 采集适配器）

同行广告情报的**结构标注、配方库、喂进生成**已全部就绪并真机验证；
缺的只是从各平台透明库拉原始观测的采集层。

| 平台 | 需要什么 | 说明 |
|---|---|---|
| Meta Ad Library | Meta 开发者 App + Ad Library API 访问（需身份验证流程） | 官方公开接口，免费，但要走 Meta 的验证 |
| TikTok Commercial Content Library | 研究者/商业 API 申请 | 官方接口，需申请审核 |
| Google Ads Transparency | 无官方 API；用 Apify actor 或 SerpApi | **`APIFY_TOKEN` 已有**，加对应 actor 即可，可能只需加预算 |

**务实建议**：三个平台都可以先走 Apify 的现成 actor（我们已有 token 与集成），
一分钱新 key 都不用开，只是 Apify 用量会涨。官方接口等量起来再申请。
