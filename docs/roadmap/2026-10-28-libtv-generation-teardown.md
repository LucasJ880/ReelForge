# LibTV 出片逻辑拆解与本轮借鉴（2026-10-28）

来源：LibTV「创作精选 · 商业广告」里一条公开作品《洁净，自有从容》（高端洗地机 TVC），其「查看制作过程」只读画布的公开接口
`api.liblib.tv/api/community/project/template/detail?projectTemplateUuid=27a4f985638b40efab7220ec16be9ab5`
返回整张画布（71 个节点、193 条连线，含每个节点的提示词、模型、参数与输入）。原始 JSON 不入库（第三方作品），这里只记方法。

## 1. 他们的画布结构

| 分组 | 内容 | 模型 |

| 产品 | 商家实拍多角度 + 生成的「产品三视图 / 多视图」 | 图像模型 + 三视图模板 |

## 2. 视频提示词的写法（质量的真正来源）

每条视频提示词由四块组成：

1. **全局质感圣经**（每个图像、视频节点逐字相同）：统一调色、曝光与饱和度、材质物理（金属长条反射、塑料粗糙度、液体折射）、构图原则、运镜速度，以及一长串「禁止」（动画感、廉价 3D、过度锐化、HDR、悬浮界面、字幕、BGM、橙青对比……）。
2. **参考使用说明**：每张参考图编号并写明锁定范围——「{{Mixed 2}}{{Mixed 3}} 是唯一锁定产品形状、结构、比例和颜色」「{{Mixed 1}} 是女主人物锁定」「{{Mixed 5}} 锁定污渍位置与行进方向」「{{Mixed 7}} 只用于镜头 07」「{{Mixed 6}} 是开场目标首帧」。
3. **时间码镜头表**：`00:00–00:02｜镜头01｜24毫米厨房贴地建立镜头`，每镜写焦段、机位高度（离地 12 厘米）、前中后景、一个有幅度的动作（向前半步、移动一个机头宽度）、运镜、**镜头结束时的状态**、`同步声音`、`无旁白`；镜头间写 `Hard Cut`；产品不变量写进镜头（「机身不旋转、不变宽，也不出现额外按钮」「观察窗内不得生成数字、图标或文字」）。
4. **旁白锁**：台词逐字、时间窗（`00:08.0—00:11.2`）、音色参考音频、「不生成音乐、字幕、人物对白或第二位配音演员」。

另：跨段连续性靠把上一段成片作为下一段的参考输入，并在提示词里写「镜头 12、13 回到同一片污渍区域，方向必须延续第一段」。

## 3. 和我们的差距（改动前）

| LibTV | 我们（改动前） |
|---|---|
| 每镜写焦段 / 机位 / 前中后景 / 动作幅度 / 结束状态 / 同步声 | 故事板节奏是 4 句固定模板（「3–7s · faithful product reveal」）；派发视频时镜头表被换成「recreate storyboard keyframe N — 模板句」，**LLM 写的镜头细节在故事板路径上整段丢弃** |
| 参考图编号 + 每张的锁定范围 | 单条路径有 `REFERENCE IMAGES` 行（已有）；**批量路径只点名了实拍槽位，故事板帧（第 k+1 张起）没有任何说明**——1026 的 5 条漂移全在批量 |
| 全局质感圣经 + 产品不变量 | 只有风格关键词与可选的一致性锁 |
| 旁白时间窗 + 单一配音 | 只有「逐字台词」，没有时间窗 |
| 资产准备：产品三视图、空镜场景板、角色卡 | 只有商家实拍 + 故事板帧 |
| 同提示词多模型择优 | 单次出片 |

## 4. 本轮已落地（小范围）

- **故事板镜头卡**（`src/lib/video-generation/shot-cards.ts`）：建单条故事板时 LLM（fast 档，gpt-5.6-terra 首选，40s 超时）按商家原话给每帧写一张卡（焦段景别 / 机位与运镜幅度 / 前中后景 / 动作 / 结束状态 / 同步声）。卡写进帧提示词一行 `SHOT CARD:`（免迁移），出帧按卡构图；重做沿用同一张卡；派发视频时读回，镜头行变成 `0-4s · shot 1: recreate storyboard keyframe 1 (reference image 3) — … <卡>`，镜头间 `(hard cut)`，并加三行：`LOOK`（全局质感与禁止项）、`PRODUCT INVARIANTS`（产品不变量）、`SPEECH TIMING`（单一配音、在段尾前 1 秒说完）。LLM 不可用 / 超时 / 输出不合格 → 与改动前逐字节一致。开关 `STORYBOARD_SHOT_CARDS=off`。批量故事板不设计卡（批量视频沿用模板自己的时间线）。
- **批量参考图说明**（`src/lib/video-generation/batch-reference-manifest.ts`）：按截断后真正发出的张数写「input_images[1]-[k] 是实拍、[k+1]-[m] 是已批准故事板帧，冲突时以实拍为准」，与模板 `{IMAGE_REFS}` 同一记法；超 5000 字原样返回。

## 5. 没做（留作后续，按收益排序）

1. **产品参考板**：把商家多张实拍确定性拼成一张「多视图参考板」（不经 AI 重绘），省参考图槽位并给模型几何全貌——对应 LibTV 的产品三视图，但不冒 AI 三视图改形的风险。
2. **空镜场景板**：先出无人无产品的场景，再在场景上放人放产品——对 SCENE GEOMETRY 漂移最有效，但要多一轮出图。
3. **段间连续性**：多段视频把上一段尾帧作为下一段参考（需要串行生成，时延翻倍）。
4. **同提示词多次出片择优**：成本 ×N，适合作为付费「精修」档。
