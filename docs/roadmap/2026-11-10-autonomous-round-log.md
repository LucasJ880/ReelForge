## 每次上线的固定步骤

1. `npm run typecheck` + `npm run lint` + 全量测试（Node 22+：`PATH=/opt/homebrew/bin:$PATH node --import tsx --test tests/*.test.ts`）全绿。
2. 前端改动在本地预览里实际点一遍（`preview_start name=app`，真机模式、CEO 测试账号已登录）。
3. 带迁移：先在分支上 `npm run db:migrate:deploy`，再合并。
4. 开 PR 直接对 `main`（不叠 PR）→ 等 CI → `gh pr merge <n> --merge`。
5. 合并后看 `/api/health` 的 `release` 是否等于新提交，再看 prod-smoke 工作流。红了先读日志。
