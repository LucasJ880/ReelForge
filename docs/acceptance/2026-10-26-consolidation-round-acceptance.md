## 3. C5 模板样片（14 个）

单条真实成本：15 秒样片 ≈ 1,400 点（Seedance 720P 84–104 点/秒 + 故事板帧），**不是**脚本常量里的 900。

| 模板 | 结果 | 人工 QA |
|---|---|---|
| commerce-pet-companion 萌宠陪伴 | 成片 | 过：全程同一只金毛（上轮失败点），玩具一致 |
| commerce-demo-first-reveal 先演示后揭晓 | 成片 | 过：先佩戴效果后揭晓充电仓，产品一致 |
| commerce-single-feature-proof 单卖点硬证据 | 成片 | 过：面料挂水珠（防水）→ 卷口扣合 → 林间实拍 |
| commerce-dual-context 一物双景 | 成片 | **不过**：15 秒都在同一张沙发，没有第二个场景（连续第三次，配方问题） |
| commerce-gift-unwrap 礼盒仪式感 | 成片 | **不过**：结尾出现两瓶（参考图一瓶），产品数量漂移 |
| commerce-triple-proof 一点三证 | 成片 | 过：同一只腕表三段证据（中间的半透明是转场叠化） |
| commerce-aesthetic-mood 氛围质感种草 | 成片 | 过：单瓶精华、滴管特写，产品一致 |
| commerce-problem-solution 痛点解决方案 | 成片 | 过：空沙发 → 杂乱 → 放上靠枕 → 坐下；预览起点改 11 秒（6 秒起裁到头） |
| commerce-hard-sell-presenter 高转化主持带货 | 成片 | 过：同一位主持人、同一个牛皮纸袋；人物模板按上部裁切做预览 |
| commerce-ugc-testimonial UGC 真实口碑 | 成片 | **不过**：中段换了一个人（人物漂移） |
| commerce-unboxing-transform 开箱场景转化 | 成片 | **不过**：耳机变成第三方（AirPods 式）外观，产品漂移 |
| commerce-value-proof 价值感证明 | 成片 | **不过**：皮表带变成绿色尼龙带，并多出第二只钢带表 |
| commerce-home-space-styling / commerce-fashion-lookbook | 供应商处理中（> 50 分钟） | 生产轮询继续收；出片后补 QA |
