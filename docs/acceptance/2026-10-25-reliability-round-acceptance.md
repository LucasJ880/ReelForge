## 2. 验收中发现并已修复上线的问题（按影响排序）

1. **生产成片中文字幕全是豆腐块**（影响所有带中文字幕的单条成片，历史 6 条 / 3 个账号）。
   拼接跑在 GitHub Actions Ubuntu runner（apt ffmpeg），系统无中文字体、也没传 fontsdir；
   Vercel 上的媒体探针走的是另一条路径，所以一直是绿灯。runner 现在装应用同版本字体包并传 fontsdir + fonts.conf，
   ASS 样式 family 改为打包字体真实名；探针改为「没选中打包字体就判失败」。已用生产 runner 重拼验证。
2. **视频不按已确认的故事板拍**：提示词走通用 UGC 配方（LOCATION 写死居家晨光），商家写的场景一个字没进去，
   还把上传文件名（UUID）当产品名写进提示词。派发时按故事板改写：商家原话 + 帧序 / 时间窗 / 参考图序号。
3. **故事板帧画成四宫格 / 五宫格拼图**：先写这一帧、故事只作背景、单镜头硬约束（重做也带上）。
4. **单条视频提交后客户无处取消**（铁律 #7）：新增成品库详情「取消这条」，额度立即返还、素材保留；
   取消不算失败（不进「需要处理」、不拉低成片率）。
5. **合成「重试」一分钟内被判排队超时**：排队超时改从重新排队时刻起算（客户重试与超时续跑两条路）。
6. **返还截止线晚于真实部署**：截止线定为 `6e32081` 部署完成时刻 20:21:31Z（原 20:45 把真实取消挡在线外）。
7. **单条故事板「提交确认未知」帧承诺自动重投但没人重投**：轮询里自动重投一次（只救 30 分钟内刚失败的）。
8. 口播初稿把视频提示词念出来（「15 秒 9:16 UGC」）且半句截断；画幅被切出「16」。
9. 「.png 名、JPEG 内容」的图被拒（手机 / 微信常见）：按签名类型收下并存储。
10. 内容计划兜底把整句原话塞进标题；「重新排一周」同一句话永远回放旧计划（幂等键按内容取，且开头相同会串单）。
11. OpenAI 无额度时实拍线路 / 图文出图提示「请重试」：改为 503 + 如实说明正在恢复。
12. 文案：额度「成片后计」→「提交时预占，失败与取消返还」；批量确认页不露供应商套餐原名 / CDN；
    故事板节奏名中文化；关键帧未画完流程不标已完成；询盘页 / 实拍线路默认文案去行业化。
