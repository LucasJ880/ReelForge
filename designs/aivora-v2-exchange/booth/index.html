开展前一晚 · The night before

  1. 在 booth/config.json 填三项：resultBase（结果页公网地址，先把 booth/ 部署到我们自己的域名，并同时上线 /api/lead）、leadFallback（访客提交失败时给出的邮箱 / WhatsApp / 微信）、consentEntity（征求同意的法律主体、地址、邮箱）。所有设备都从中继读这一份。
    Fill resultBase, leadFallback and consentEntity in config.json; every device reads it from the relay.
  2. 跑 node designs/aivora-v2-exchange/booth/tools/relay-selftest.mjs 和 tools/draft-cases.mjs，都应全绿；改过页面文字就跑 tools/build-fonts.py。
    Run both self-tests; rebuild fonts after text changes.
  3. 在展台大屏上打开 screen.html?fitcheck，底部应显示 FIT OK；否则按列出的元素删短文字。
    Open screen.html?fitcheck on the actual big screen; it must read FIT OK.
  4. 用一台关掉 Wi-Fi、只用 4G/5G的手机扫店主台的二维码，打开结果页并提交一条测试留资，确认它真的进了库。
    On a phone with Wi-Fi off, scan the QR, submit a test lead and confirm it arrived.
  5. 证据面只放真实数据：拿到平台 ID 和 Sunny Shutter 书面同意后，再填 proof，并把 consentOnFile 设为 true、asOf 填日期。
    Proof shows real data only.

展台上怎么接 · Booth setup

  1. 带一台随身路由器（或手机热点，设密码），笔记本、两台 iPad、大屏都连上它。不要用展馆的开放 Wi-Fi。
    Bring a travel router or a password-protected phone hotspot; never use open venue Wi-Fi.
  2. 笔记本接电源、不合盖，终端里运行 caffeinate -dims 防休眠，再运行 node designs/aivora-v2-exchange/booth/relay.mjs，在每台设备上打开它打印出来的地址。
    Keep the laptop awake (caffeinate), run the relay, open the printed URL on each device.
  3. 大屏开「大屏」，用 Chrome 的 kiosk 模式（--kiosk）或按 F11 全屏；点一下屏幕会自动全屏并保持常亮。iPad A 开「客户手机」，iPad B 开「店主台」；两台 iPad 自动锁定设为「永不」，并开「引导式访问」锁在页面上。
    Big screen full-screen (kiosk/F11); iPads: Auto-Lock never + Guided Access.
  4. 每台设备右上角显示「展台局域网已配对」才算连上；显示「未连上展台网络」就检查 Wi-Fi。
    Every device must read "Paired over booth Wi-Fi".
  5. 没有笔记本时：需要先把 booth/ 部署到公网并联网，用一台设备开「单屏演示」；同一台设备再开一个「大屏」窗口会自动配对（只适合这台设备自己接电视）。随身带一段全流程录屏兜底。
    No laptop: requires a public deploy and internet; same-device windows pair automatically. Bring a screen recording.
