## 线上对齐导演线路：做完了（11-17）

**线上创作台出的片，现在和导演线路（Claude 这边）用同一套规则、同一个提示词拼法。** 有实拍图的 15 / 30 秒单条片：

1. 点「生成 AI 故事板」→ 服务端让导演写手（`director-writer.ts`，gpt-5.6-sol 看图）写一份镜头脚本，用导演线路的校验把关、不合格送回去改，
   最多三稿、总预算 200 秒；写不成就退回老的四 / 五帧故事板并记一条降级（`director_script`，面板上有一句人话）。
2. 故事板只出**一张开场帧**（Shuyu 的 GPT Image 2 高质量档），面板显示这一帧 + 每个镜头的时间、台词和动作。脚本存在
   `StoryboardRun.visualReference`（JSON，没加列、没有迁移）。
3. 确认后出片：**整条一次生成**（15 秒六七个镜头、30 秒十二个镜头，不再两段 15 秒拼），提示词就是 `buildVideoPrompt(job)`，
   参考图 = 实拍图在前、开场帧最后；口播、配乐、音效由出片模型原生给。30 秒一条 1,500 点（原来两段 3,000 点）。
4. 合成：字幕按脚本里每句台词所在镜头的时间烧（开了语音识别就跟着人声走）；不裁尾；可选右上角 Logo。

跟着做的几样：

- **模板**：「自动匹配（推荐）」不再是正则——片种和拍法由导演写手按商品定；新增「电商快销」（片种定成快销）。别的 34 个模板仍走老线路。
- **右上角 Logo**：创作页「更多设置」里一个开关，图取用户自己默认品牌包的 Logo，做成透明的白色图形角标（和导演线路的 `post` 同一套版式）。
  透明底 PNG 按透明度取形状，白底深色线稿按深浅取形状；彩色加白底的会变成一整块，品牌页那句提示还没加。
- **出图统一走 Shuyu**（用户 11-17 定）：导演命令行的 `frames` 缺省也走 Shuyu 的 GPT Image 2（`--provider openai` 可退回）。OpenAI 只留写脚本、出方案。
- **探厂 / 探店**：写手的系统提示词加了一节，场所实拍图标 `scene`，只有场所图没有商品图也能写。
- **人脸**：Shuyu（Kelin）11-17 答复不卡人脸、只卡涉黄。规程里的默认做法没变（开场帧不画脸，是为了前后一致），那条 5 秒的带脸测试还没重跑。
- 总开关 `DIRECTOR_LINE=off`（Vercel 环境变量，缺省开）：一键退回老线路。

| 问题 | 根因 | 改法 |

## 每一批怎么验（这次踩过的坑）

```bash
export PATH=/opt/homebrew/bin:$PATH        # 要 Node 22+
npm run lint
node --import tsx --test tests/*.test.ts   # npm test 的 glob 在这台机器上不展开，用这条
npx next build
rm -rf .next/dev/types                     # 再跑类型检查
npm run typecheck
```

- **类型检查要放在 `next build` 之后跑**：`.next/types` 里是上一次构建生成的路由类型，删了接口之后它还指着旧文件，会报假错。
- 子任务在隔离的工作副本里做删除，回来后**自己重跑一遍**上面这套再推；它们的 `ai-context/` 不要用，在主仓库里 `npm run codemap:build` 重建。
- 推上去后看发布后冒烟：`gh run list --limit 3`，名字是 `prod-smoke`，对上提交号。
- 生产库只做只读查询；任何 `db:*` 都别跑。瘦身和线上对齐都没有任何迁移。
- **工作副本里别 `git add -A` 把 `public/brand` 的软链带进提交**：11-17 这样提交的一个暂存提交被 cherry-pick 回主仓库时，
  把主仓库那个不进 git 的真目录换成了指向自己的软链（构建直接失败）。已从内容一致的旧副本恢复，`.gitignore` 也把软链形式加进去了。
- 判断「被内容挡了」之前先排除 Shuyu 故障：拿一条已知能过的素材当对照。
