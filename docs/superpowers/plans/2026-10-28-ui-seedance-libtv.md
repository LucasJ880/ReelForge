# 2026-10-28 UI 改版：首页学 Seedance 2.5 官网，工作台学 LibTV

依据：Evan 2026-10-28「首页照 Seedance 2.5 官网做，大视频背景；登录后的工作台照 LibTV；现在的交互和 UI 落伍、复杂」。
逆向分析：`docs/reference/taste/seed.bytedance.com.md`、`docs/reference/taste/liblib.tv.md`（Design Map + Taste DNA）。

## 方向（取代 DESIGN.md 的 Aivora Exchange「深海交易所」）

两家共同点就是我们的新规矩：**界面是灰的，颜色只来自成片**。

| | Seedance 2.5 官网（首页） | LibTV（工作台） |
|---|---|---|
| 场 | 第一幕：全屏静音视频轮播（#18191B 垫底）；第二幕：浅灰画廊 #F8F8F8 | 近黑中性灰 #121212 / #141414 / #171717，白 5–6% 抬升面 |
| 字 | 单一字族，首屏 100px/600/−2px 一句标题，正文 16px | 系统字 11–14px，4px 节奏 |
| 按钮 | 视频上：白 20% + blur 12px 胶囊；浅底上：实心浅灰圆 | 一屏只一个白色实心胶囊主行动 |
| 内容 | 每节 = 32px 标题 + 一句话 + 600px 高的「输入 → 成片」横向轮播 | 一张「新建创作」大卡 + 一排工具 + 按角色分的素材墙 |
| 去掉 | 眉题、要点列表、读数、徽章 | 读数墙、图表、引导清单 |

对现行 Exchange 的取舍：
- **去掉**：冷蓝色调、工程网格、行情条、实时生产带、编号导轨、状态栏时钟、「行情头」读数墙、交易所隐喻文案。
- **保留**：颜色只给数据/媒体的原则、token 闭环（字面量只住 `tokens.css`）、tabular-nums、`'use client'` 安全、可访问性（焦点环、减少动效）。
- **放开**：毛玻璃只允许出现在视频之上（首页第一幕），门禁测试改为「backdrop-filter 只能出现在 `.on-media` 作用域」。

## 分期

1. **P-UI-1 首页（/）**：第一幕全屏视频轮播 + 底部左下大标题 + 一句话 + 三个等宽胶囊（免费试做 / 看样片 / 申请陪跑）+ 「开声」胶囊；第二幕浅灰画廊：3–4 节「商品实拍 → 成片」配对轮播；第三幕样片瀑布流；页脚。首屏片子用 Seedance 2.5 新出一组暖调小商家场景（16:9，约 4 × 10s × 130 点/秒 ≈ 5.2k 点），出片前给 Evan 看分镜。
2. **P-UI-2 工作台外壳 + 首页（/app）**：240px 左侧栏（首页 / 作品 / 素材；创作：单条视频 / 批量 / 模板；获客：询盘 / 赢家 / 状态）、「新建视频」大卡 + 工具格 + 最近作品 + 精选模板；中性灰 token 替换冷蓝。
3. **P-UI-3 创作页故事板视图**：素材按 商品 / 人物 / 场景 分组，帧墙与视频墙（时长角标），镜头卡可见可改。
4. **P-UI-4 DESIGN.md 与门禁**：重写 DESIGN.md、更新 `exchange-design-system` / `design-system-closure` 门禁、视觉基线。

每期：typecheck + lint + 相关测试 + 本地预览点一遍（console 无报错）+ 截图给 Evan。
