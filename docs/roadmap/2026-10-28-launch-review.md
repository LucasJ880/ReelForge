## 0. 结论

1. **供应商收敛**：
   - Runway 一个 key 承担视频（Seedance 2.5）、故事板出图（GPT Image 2）和配音（ElevenLabs）。
   - OpenAI 只留文字与看图（简报、镜头卡、口播稿、商品识别），remove.bg 只留抠图，Shuyu 降为备用线路。
   - 其余视频、图像、语音接口逐步退役。
2. **交互对齐主流工作台**：第一屏就是一个 AI 对话框（说想做什么 + 传商品图）。AI 先给出一份**看得懂、能改的创作简报**，再出故事板、成片，都在同一条会话里。批量就是对话框里的「条数」。
3. **CEO 的担忧**这样解：
   - 商家不写提示词，只说人话或点「帮我写」。
   - AI 的理解以中文简报和镜头卡摆出来，可以改。
   - 原始英文提示词收在「查看提示词」里，想看的人能看。
4. **导航收成 5 个**：创作、成品库、品牌套件、模板、指南。早已下线入口的旧板块，单独提一个删除 PR 删代码（数据库只留不删）。

## 3. CEO 的两个担忧

**「没有自动生成提示词，商家会不会嫌麻烦」**：主流做法是不让商家写提示词，只让他说人话，AI 来写。我们后台本来就是这么做的，缺的是**前台看得见**和**零输入起步**。
- **帮我写**：传了商品图、描述还空着时，点一下，AI 看图写一段两三句的描述，商家可以改。Runway Product Shot 的「自动提炼简报」就是这个。
- **模板一键起步**：模板本身就是固定好的提示词（你和 CEO 聊的就是这个），对话框下面摆一排「试试这些」芯片，点了直接填好。
- 对话框里的示例占位文案换成真实商品的说法（现在是 UGC 浴室的例子）。

**「同行直接把提示词给用户看」**：看得见可以，但别把写提示词的负担转给商家。
- 出故事板前，AI 先回一张**创作简报卡**（中文）：拍什么、谁出镜、在哪、卖点、四个镜头各拍什么。商家能直接改，改完再出图。
- 故事板每帧继续带**镜头卡**（已有）。
- 完整英文提示词放在「查看提示词」折叠里，给想研究的人看，不要求改。

## 4. 新的工作台交互

**创作 = 一个对话框**（参照 Runway 首页与 LibTV 的 Agent）：

```
┌──────────────────────────────────────────────────────┐
│  今天想拍什么？                                          │
│  [商品图 +] [参考 +]                                     │
│  例：把这只保温杯拍成通勤广告，地铁站和办公桌，热一整上午  │
│                                         [帮我写] [生成 →] │
└──────────────────────────────────────────────────────┘
   15s ▾   9:16 ▾   模板：自动 ▾   条数：1 ▾   ⚙ 口播 · 字幕 · 音乐
   试试这些：[通勤带货] [开箱质感] [痛点到效果] …（模板）
```

- 点「生成」后，下面展开**同一条会话**：创作简报卡（可改）→ 故事板四帧（单帧重画、确认）→ 生成进度 → 成片（下载、重做一段、换字幕或音乐）。刷新后整条会话恢复（现在已能恢复故事板）。
- 现在表单里的口播稿、字幕样式、BGM、参考模式，收进卡片下面的「⚙」浮层。默认值都替商家定好，不展开也能出片。
- **批量 = 条数 1 / 2 / 4**：同一商品、同一简报，每条只换一个变量（开头钩子、场景或卖点），一次出几条做对比。这是 Runway Ads 的「一次一个变量」，比 Creatify 的 50 条轰炸更适合小商家的预算。
  - 现有的「批量生产」向导（模板 × 商品）先挪到「更多」里留给内部批量。条数功能跑顺后再按 A→B→C 退役。
- **品牌套件**（参照 Runway Brand Kits，即计划里的 P1 商品库）：
  - 商品：实拍、自动抠图、自动描述、logo。
  - 品牌：品牌名、色值、一句 CTA。
  - 对话框里可以用 @商品 引用；首次也可以贴网站或商品链接自动起草（链接导入已有）。
- **导航**：创作 · 成品库 · 品牌套件 · 模板 · 指南（「批量生产」「品牌」合并进上面两处）。
